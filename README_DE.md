# AlgoSphere – öffentliche Projektübersicht

AlgoSphere ist ein unabhängiges Forschungs- und Entwicklungsprojekt für ein nachvollziehbares Crypto-ML-Handelssystem. Der Schwerpunkt liegt darauf, Research, Backtest, Paper, Shadow und später Live-Ausführung technisch und kausal miteinander in Einklang zu bringen.

Dieses Repository veröffentlicht ausschließlich bereinigte Projektdokumentation. Programmcode, Zugangsdaten, Marktdaten, Modelle, Datenbanken und proprietäre Strategiedetails bleiben privat.
