## How to read AlgoSphere status language

AlgoSphere deliberately separates several kinds of “done”.

| Term | What it means here |
|---|---|
| **Implemented** | The relevant code or contract exists. |
| **Tested** | Focused checks passed for the stated scope. |
| **Runtime proven** | The relevant behavior was observed in the running system. |
| **Browser/UI proven** | The intended state was also visible in the served user interface. |
| **Prospectively proven** | The behavior was observed on new, naturally arriving evidence after the change. |
| **Insufficient evidence** | The mechanism may work technically, but there is not enough evidence for a scientific/performance conclusion. |
| **Open / blocked** | The work is not complete or cannot safely continue yet. |
| **Historical / legacy gap** | Older evidence is incomplete and is not silently reconstructed. |

A green test is not a profitability claim.  
A completed training run is not automatically a good model.  
A newer model is not automatically promoted.  
A Demo is not Live trading.

## What is public here?

This repository is the public documentation and evidence layer.

It includes status, methodology, selected evidence, verification summaries and small tools that verify the public export itself.

It does not include the private AlgoSphere trading/runtime application, private model bundles, proprietary strategy parameters, credentials or account data.

See [Public Repository Scope](project/PUBLIC_REPOSITORY_SCOPE.md) and [Licensing](legal/LICENSING.md).
