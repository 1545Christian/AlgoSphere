Wenn du AlgoSphere zum ersten Mal siehst, musst du nicht jede Datei in diesem Repository lesen.

Der schnellste Einstieg ist:

1. **[Projektrichtung](project/PROJECT_DIRECTION_DE.md)** — wohin AlgoSphere entwickelt wird.
2. **[Aktueller Status](../CURRENT_STATUS.md)** — was heute wirklich funktioniert, bewiesen oder noch offen ist.
3. **[Neuestes Update](../updates/2026-09-21-public-status_DE.md)** — was sich zuletzt geändert hat.
4. **[Evidence-Übersicht](../evidence/EVIDENCE_SUMMARY.md)** — wie öffentliche Evidence dokumentiert wird und wo ihre Grenzen liegen.
5. **[Roadmap](progress/ROADMAP.md)** — was als Nächstes ansteht.

## Wie die Statusbegriffe gemeint sind

AlgoSphere trennt bewusst verschiedene Arten von „fertig“.

| Begriff | Bedeutung im Projekt |
|---|---|
| **Implementiert** | Der relevante Code oder Contract existiert. |
| **Getestet** | Fokussierte Prüfungen für den genannten Umfang sind grün. |
| **Runtime bewiesen** | Das relevante Verhalten wurde im laufenden System beobachtet. |
| **Browser/UI bewiesen** | Der beabsichtigte Zustand war auch in der ausgelieferten Oberfläche sichtbar. |
| **Prospektiv bewiesen** | Das Verhalten wurde nach der Änderung an neuer, natürlich eintreffender Evidence beobachtet. |
| **Insufficient Evidence** | Technisch kann der Mechanismus funktionieren, aber für eine wissenschaftliche oder Performance-Aussage reicht die Evidence noch nicht. |
| **Open / Blocked** | Die Arbeit ist noch nicht abgeschlossen oder kann aktuell nicht sicher fortgesetzt werden. |
| **Historical / Legacy Gap** | Ältere Evidence ist unvollständig und wird nicht still erfunden oder rekonstruiert. |

Ein grüner Test ist kein Profitabilitätsbeweis.  
Ein abgeschlossener Trainingslauf ist nicht automatisch ein gutes Modell.  
Ein neueres Modell wird nicht automatisch promotet.  
Eine Demo ist kein Live-Trading.

## Was ist hier öffentlich?

Dieses Repository ist die öffentliche Dokumentations- und Evidence-Schicht.

Enthalten sind Status, Methodik, ausgewählte Evidence, Verifikationszusammenfassungen und kleine Werkzeuge, die den öffentlichen Export selbst prüfen.

Nicht enthalten sind die private AlgoSphere-Trading-/Runtime-Anwendung, private Model Bundles, proprietäre Strategieparameter, Zugangsdaten oder Kontodaten.

Siehe [Umfang des öffentlichen Repositorys](project/PUBLIC_REPOSITORY_SCOPE_DE.md) und [Lizenzierung](legal/LICENSING.md).
