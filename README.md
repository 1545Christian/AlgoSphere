## Overview

MIOIQ combines quantitative market analysis, market-state and regime research, rule-based and ML validation, evidence-linked Decision → Outcome → Learning workflows, external AI-assisted analysis, Paper / Shadow execution, lifecycle governance and future Demo / Packaging / Release work.

The project focuses on reproducibility, causal evaluation, explicit lineage and preserving both positive and negative evidence.

## Where this is heading

MIOIQ is being developed toward a configurable quantitative research and trading-analysis system that can work across a broad universe of crypto markets.

The long-term goal is not to force one model or strategy across every market. It is to learn, with measurable evidence:

- which classes of approaches work under different market conditions
- when a Rule approach is stronger than ML
- when a model should be revalidated
- when a strategy should remain in research instead of being promoted
- and when the better decision is simply **NO_TRADE**

Research, validation and evidence handling should become increasingly automated while promotion, execution permissions and any future real-capital use remain explicitly governed.

Exact private strategy logic, model internals and execution rules are intentionally not published.

## Research lifecycle

HYPOTHESIS → QUICK → ROBUST_OOS → CHALLENGER → PAPER → CHAMPION

A newer model does not become active simply because it is newer. Promotion is intended to depend on reproducible evidence and controlled comparison.

## Evidence and transparency

MIOIQ publishes selected reviewed project status, research summaries, verification results, evidence records, development history and known limitations.

Negative results remain visible. Technical completion is not presented as proof of model quality, profitability or live readiness.

## Public / private boundary

This repository is the **public documentation and evidence layer** for MIOIQ.

It does **not** contain the private application/runtime source code, credentials, account configuration, private market databases, trained private model bundles, proprietary strategy parameters, exact thresholds, feature/label definitions, scoring logic, private prompts, execution formulas, venue-routing logic or internal implementation details that would materially reduce the effort required to reconstruct the private system.

There is currently no public MIOIQ application download from this repository.
